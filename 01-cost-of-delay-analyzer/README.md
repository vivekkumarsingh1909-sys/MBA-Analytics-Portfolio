# Cost of Delay Analyzer

## Problem Statement
Delays in the approval and invoice stages of the purchase-to-pay process lead to lost early-payment discounts and penalty costs for a company. This project measures the waiting time at each stage, estimates its cost in ₹, and predicts which cases are likely to be delayed, so that bottlenecks can be fixed before they cause losses.

## Objectives
1. Identify the stages with the longest waiting time.
2. Estimate the financial cost of these delays.
3. Predict delay-prone cases at the time of purchase order creation.

## Tools
PostgreSQL, Power BI, Excel, Python
